# 5E ATLAS — prototipo UX/UI

Prototipo unico e cliccabile: Home, Biblioteca, Incantesimi, scheda Palla di fuoco, Lettore con indice e pager. Non è il sito di produzione: serve a validare gerarchia, densità e comportamento mobile prima di toccare `main`.

- **Preview:** https://atlas-ux-prototype-53shyz63g-hybrid-art.vercel.app/
- **Mobile:** 390 px, poi desktop 1440 px.
- **Direzione:** guscio scuro ATLAS, pergamena solo nel contenuto di lettura e nella scheda incantesimo.
- **Stati:** ricerca, filtro 2024 core, ritorno dalla scheda, indice in dialog nativo, tabella larga con scroll interno.
- **Font:** Modesto, Modesto Condensed, Mulish, Lora in `fonts/`.
- **Dati demo:** Fireball XPHB livello 3, 1 action, 150 ft, V/S/M, istantanea.

Aprire `index.html` o servire la cartella con un server statico. Il prototipo non usa build né dipendenze.
